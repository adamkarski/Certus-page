Analiza typografii i konkretne poprawki
1. Tekst główny (opis, paragrafy)

Na desktopie opisy wyglądają za duże w porównaniu do nagłówków i przestrzeni wizualnej.

Rozwiązanie:

body {
  font-size: clamp(0.9375rem, 0.35vw + 0.85rem, 1.0625rem); /* 15px–17px */
  line-height: 1.6;
}


Klucz: zachować minimum ~15 px na mobile, ale delikatnie zredukować na większych ekranach.

2. Nagłówki — ujednolicony wzrost bez przesady

Nagłówki dzielą strukturę wizualną, ale muszą być proporcjonalne.

h2 {
  font-size: clamp(1.5rem, 1.2vw + 1.05rem, 1.875rem); /* ok. 24–30px */
  line-height: 1.25;
}
h3, .section-title {
  font-size: clamp(1.3125rem, 0.8vw + 1rem, 1.5rem); /* ok. 21–24px */
  line-height: 1.3;
}

3. Formularz kontaktowy — etykiety i przycisk

Etykiety pól ("Imię", "Email") i przyciski ("Wyślij wiadomość") wyglądają duże i „ciężkie”.

Zmniejsz czcionkę dla etykiet i przycisków, zachowując czytelność:

form label, button {
  font-size: clamp(0.875rem, 0.2vw + 0.8rem, 1rem); /* 14–16px */
}
button {
  padding: 0.6em 1.2em;
}

4. Drobniejsze teksty (kontakt, adres, polityka prywatności)

Można je jeszcze bardziej stonować:

.footer, .footer a, .contact-info {
  font-size: clamp(0.8125rem, 0.15vw + 0.75rem, 0.9375rem); /* 13–15px */
  opacity: 0.9;
}

5. Kontener tekstowy — ograniczenie szerokości

Obszary tekstowe są szerokie, co powoduje trudność w odbiorze i poczucie rozwlekania.

.container--text {
  max-width: 65ch;
  margin: 0 auto;
  padding: 0 1rem;
}


Zachowaj regułę także dla formularza (więcej kontroli nad szerokością).

6. Spójność i usuwanie nadpisów

Masz melodramatyczne „nadpisy” czcionek w CSS? Usuń je — zamiast:

p { font-size: 18px !important; }


Używaj klas (.desc, .lead) i rem.

Podsumowanie

Po wprowadzeniu tych zmian:

Opisy tekstowe będą lepiej dopasowane wielkością, nie będą „krzyczeć” na stronie.

Nagłówki zachowają swoją funkcję, ale bez przesady.

Formularz kontaktowy będzie kompaktowy, schludny, z przyjazną czcionką.

Szerokość tekstu (!-czytania) będzie lepiej dopasowana, co skończy problem „rozwlekania”.

Cała typografia będzie skalowalna i spójna — rem + clamp to przyszłościowe podejście.



h1, h2, h3 {
  font-family: 'Montserrat', 'Helvetica Neue', Arial, sans-serif;
  font-weight: 700;
  line-height: 1.2;
  margin-bottom: 0.5em;
  color: #1a1a1a; /* ciemniejszy dla lepszej czytelności */
}

h1 {
  font-size: 2.5rem; /* ~40px */
  letter-spacing: -0.5px;
}

h2 {
  font-size: 1.75rem; /* ~28px */
}

h3 {
  font-size: 1.25rem; /* ~20px */
  font-weight: 600;
}
2. Tekst paragrafów
Obecnie wygląda „systemowo”. Dajmy mu lekkości i profesjonalizmu:

css
Skopiuj kod
p {
  font-family: 'Open Sans', 'Helvetica Neue', Arial, sans-serif;
  font-size: 1rem; /* ~16px */
  line-height: 1.6;
  margin-bottom: 1em;
  color: #333; /* nie czarny, tylko lżejszy */
}
3. Przycisk „Kontakt” (header)
Twój przycisk w headerze jest teraz zwykłym linkiem.
Można mu nadać nowoczesny wygląd:

css
Skopiuj kod
header a.cta-button {
  background: linear-gradient(135deg, #ff0000, #cc0000);
  color: #fff;
  padding: 0.75em 1.5em;
  border-radius: 6px;
  font-weight: 600;
  text-decoration: none;
  transition: background 0.3s ease, transform 0.2s ease;
}

header a.cta-button:hover {
  background: linear-gradient(135deg, #cc0000, #990000);
  transform: translateY(-2px);
}
(zmień klasę .cta-button na faktyczną klasę Twojego linka w headerze — mogę to dopasować, jeśli podasz mi fragment HTMLa).

4. Nawigacja (menu górne)
Menu jest trochę „surowe”. Poprawa odstępów i efekt hover:

css
Skopiuj kod
nav ul li a {
  font-family: 'Montserrat', sans-serif;
  font-weight: 500;
  padding: 0.5em 1em;
  transition: color 0.2s ease, border-bottom 0.2s ease;
  border-bottom: 2px solid transparent;
}

nav ul li a:hover {
  color: #cc0000;
  border-bottom: 2px solid #cc0000;
}
